# Family branding

Use `FamilyBrand` for the approved Option 09 standalone calligraphic A, extended into a custom vector ALLIN wordmark with the selected appearance accent. The mark has no shield frame. `The` and `Family` use the existing app font around the vector surname.

```tsx
<FamilyBrand size="medium" />
<FamilyBrand variant="shield" size="small" />
```

Three size tokens live in `src/styles/tokens.css`:

| Size   | Mark width    | Proportional height | Supporting text | Typical use      |
| ------ | ------------- | ------------------- | --------------- | ---------------- |
| small  | 2.5rem (40px) | 2.75rem (44px)      | 0.5rem (8px)    | Sidebar, footer  |
| medium | 3rem (48px)   | 3.3rem (52.8px)     | 0.6rem (9.6px)  | Main header      |
| large  | 5rem (80px)   | 5.5rem (88px)       | 1rem (16px)     | Sign-in branding |

Pixel equivalents assume the default 16px root font. The selected A SVG uses `viewBox="25 21 150 165"` (10:11), and height is automatic. Never set an independent height or stretch the mark. Both variants use the same A sizes. Supporting text is one fifth of the mark width (80% of the previous quarter-mark size), so changing a size token scales the complete lockup together. Existing `--brand-shield-*` size/ratio tokens and the `variant="shield"` API name are retained for compatibility; that variant now means the standalone A without lettering.

The calligraphic A is followed by bespoke inline SVG L, L, lowercase-style i and N constructions: bowed downstrokes, flowing L terminals, a shorter tapered i with a flared curved foot, and a curved diagonal N. The i has a nominal 24-unit upper stem, widened around its existing centreline to echo the A leg's weight and tapered into its existing foot. The approved earlier refinement lowered the stem start from y=86 to y=108, shortening it by about 20% with its foot/baseline anchored; the vertical curves were reshaped rather than scaled. The accepted dotless design removes the separate light square above the i; the stem remains unchanged. The letter bodies lean visibly left toward the A using a 24-degree skew anchored at the y=159 baseline, matching the approximate direction of the A's descending right leg.

The letters' `-40 21 200 165` viewBox reserves room for the slanted first L. The N alone is translated six SVG units right before the shared skew, separating it from the widened, shortened i without narrowing that stem or changing either letter's vertical geometry. The translated N remains within the existing viewport after the skew. The SVG width is 4/3 of the mark token; a negative inline margin of 47/150 of that token tucks the ink close to the A without changing glyph scale. The effective layout contribution is 153/150 of the token, slightly narrower than the previous 160/150, retaining compact small/medium/large lockups. Height still scales to the A's 165-unit viewport. `The` runs upwards beside the left leg of the A, while `Family` reads downwards beside the rightmost leg of the N; both use the inherited display font at weight 800 and the fifth-mark supporting size. The component exposes the complete accessible name “The Allin Family”; decorative SVGs/text are hidden from assistive technology. It contains no link; wrap it with a labelled home link where appropriate. Gary accepted the local large login preview in dark appearance, including the dotless i and supporting-word spacing. Broader size, viewport and theme checks remain unverified.

`The` is rotated as a complete word by -66 degrees around its left bottom corner, so its baseline rises alongside the A's first/left leg (approximately 24 degrees from vertical). Its anchor sits lower beside that leg, with proportional offsets of 0.72 mark widths from the name box's top and -0.9754 mark widths from its left. With the one-fifth-mark line box, its bottom rotation anchor is at 0.92 mark widths, matching the A ink baseline at SVG y=159 within the y=21..186 viewBox. The initial accompanying left shift followed the approved -66-degree direction as the anchor moved down. An additional 0.052 mark widths left (about 2.5px at medium) now widens its side clearance to match the added Family/N gap: 0.052 × sin(66°) is approximately 0.05 × sin(71.6°), giving the same extra perpendicular separation from the adjacent leg. `The` also uses 0.03em tracking to match `Family`; its foot-height anchor remains fixed. It uses the same inherited display font and weight 800 as `Family`; both words share the reduced supporting size and existing colour, and the letters are not skewed.

The A develops the selected Option 09 calligraphic direction from `work/ui-design/family-shield-2026-10-30/option-09.html` with a fuller curved crown, tapered legs and broader terminals; its recognizable open form and original bowed crossbar remain. The body uses dynamic `--color-accent`. The crossbar is a transparent cutout using its existing path inside a luminance SVG mask, so the actual underlying surface or gradient shows through rather than a guessed background colour. Each component instance gets a unique mask ID from React `useId`, allowing wordmarks and standalone marks to coexist. `Family` rotates as a complete word by +71.6 degrees around its left bottom corner, starting with F near the top-right of the N. The outer N contour runs from (155,61) to (144,159) before its six-unit translation and shared 24-degree skew; after those transforms its endpoints differ by approximately 32.6 horizontally and 98 vertically, giving the selected baseline angle. Its top margin is 0.1 mark widths, preserving the rotation anchor height after the size reduction; the word retains its approved top placement beside the N. Its inline margin now subtracts 0.2 mark widths instead of 0.25, moving the complete word right by 0.05 mark widths (2.4px at medium) to give the descending y additional clearance; the angle and vertical position are unchanged. Its 0.03em letter spacing extends the five visible inter-letter gaps so the word spans approximately the right-leg length. At the medium 48px mark, the transformed N contour is about 33.05px long; the measured previous 28.9489px word box at 9.6px font size and -0.045em tracking gives an estimated 32.98px advance to the last letter after excluding trailing tracking. This is a proportional CSS adjustment, with endpoint alignment accepted in the local large dark login preview. Both words use the same one-fifth-mark font size and weight 800. The outward offsets of both supporting words aim for matching optical clearance from the adjacent legs, including room for the descending y; clearance was accepted in that preview; broader rendered checks remain unverified.

Custom LLiN paths also follow the accent; `The` and `Family` retain `--color-text`. The A uses `.family-logo__mark`, and the additional vector lettering uses `.family-logo__letters`. No shield outline, doorway or background panel is included. The browser favicon remains the original static cyan asset.

Before sign-in, appearance uses the last accent displayed on this browser/origin (Turquoise when absent or invalid). The anonymous `allin-family:accent:v1:browser` localStorage entry contains only an allowlisted palette ID, never an account ID. It does not identify the next person signing in. Authentication restores that person's own per-user preference immediately, including Turquoise for an account without an override. Preferences do not sync across devices; blocked storage retains the colour for the current visit but cannot guarantee restoration after reload.

Use the wordmark at family entry points and the standalone mark for compact identity. Do not replace unrelated functional icons with the family mark. `FamilyFooter` provides the shared compact footer.

The footer retains its quiet Nimbus typography, divider and spacing, and adds a
safe new-tab “Hosted by Trilogy Web Solutions” credit to the canonical clients
page. Its shared minimum link height and wrapping layout support narrow screens.
It also shows the latest known app release label from the bundled/API metadata;
see the main README for the explicit release-version procedure. Offline reads
retain the bundled/last known label without interrupting the page.
